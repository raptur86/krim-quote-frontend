- **매입·경비**: 노트북·모니터·사무실 월세·인터넷·휴대폰·도메인·호스팅·SaaS·교통비·식비 등과 비용 인정 여부
- **부가가치세**: 매출세액, 매입세액공제, VAT 포함 금액 역산, 예정/확정신고
- **종합소득세**: 사업소득, 필요경비, 소득금액, 소득공제·세액공제, 실제 예상 세금
- **증빙관리**: 사업용 신용카드, 현금영수증, 세금계산서, 카드전표, 계좌이체 증빙
- **사업자 통장/자금**: 개인 돈을 사업에 넣거나 사업 돈을 개인적으로 가져갈 때의 처리
- **자산 구입**: 컴퓨터·모니터·가구 등을 즉시 경비처리할지 자산/감가상각으로 처리할지
- **플랫폼 정산**: 고객 결제액과 실제 입금액, 플랫폼 수수료, 결제수수료, 수수료 VAT, 원천징수 구분
- **KRIM Quote 연계**: 실제 사업에서 발생하는 매출·정산·경비 데이터를 시스템에 어떻게 저장할지도 함께 설계

현재 KRIM Quote 설계에서도 **견적금액과 실제 매출을 별개로 관리하고**, 실제 대시보드 매출은 견적이 아니라 `sales_records`를 기준으로 계산하도록 되어 있어. fileciteturn0file10L190-L204 또한 고객 결제금액은 VAT 포함 금액으로 기록하고 공급가액과 매출 VAT를 역산하는 구조다. fileciteturn0file10L51-L63

그래서 앞으로는 단순히 **“세법상 어떻게 해야 하는가”**만 설명하지 않고,

**① 실제 계림 사업에서 어떻게 결제/증빙해야 하는지 → ② 장부에는 어떻게 처리되는지 → ③ 부가세·종소세에 어떤 영향을 주는지 → ④ 필요하면 KRIM Quote에는 어떤 데이터로 기록할지**

까지 연결해서 설명할게.

그리고 세율, 신고기한, 공제 요건처럼 **시기에 따라 달라지는 세법은 질문하는 시점의 최신 국세청 기준을 확인해서 답하는 것**을 원칙으로 하자.

### ChatGPT

가능해. **ChatGPT 계정이 개인 계정이라고 해서 사업 경비 처리가 안 되는 건 아니야.** 계림/KRIM의 개발·외주 업무에 실제로 ChatGPT를 사용한다면 업무 관련 소프트웨어/SaaS 비용으로 관리할 수 있어.

다만 지금부터는 **결제와 증빙을 사업용으로 정리해두는 것**을 추천해.

### 지금 개인 ChatGPT 계정 그대로 사용해도 됨

굳이 ChatGPT Business 계정을 새로 만들 필요는 없어. 현재 개인 Plus/Pro 계정에서도 청구 정보를 수정하고 Tax ID를 추가할 수 있다고 OpenAI가 공식 안내하고 있어. citeturn0search0

현재 계정에서 대략 다음 경로를 확인하면 돼.

**ChatGPT → 설정 → 결제(Billing)**

또는 UI에 따라

**설정 → 계정 → 결제 → 관리 → Billing information**

으로 들어가서 청구 정보를 사업자 기준으로 바꾸면 된다. citeturn0search0turn0search3

가능하다면 앞으로는 청구 정보에 **계림의 사업자 정보/Tax ID**를 넣고, 결제 카드도 **사업용으로 사용하는 대표자 본인 명의 카드**로 분리하는 게 가장 깔끔하다.

국세청도 개인사업자의 경우 대표자 본인 명의 신용카드를 홈택스에 **사업용 신용카드로 등록**할 수 있도록 하고 있고, 이렇게 하면 사용내역 조회와 부가세 신고가 편해진다고 안내한다. citeturn0search13

### 증빙도 받을 수 있음

웹에서 직접 ChatGPT Plus/Pro를 결제하고 있다면 결제 포털의 **Invoice History에서 과거 청구서 사본을 다운로드**할 수 있다. citeturn0search6

따라서 앞으로는 이런 식으로 보관하면 돼.

```text
ChatGPT 월 이용료
→ 사업용 카드 결제
→ OpenAI Invoice 보관
→ 카드 결제내역 보관
→ 소프트웨어/SaaS 비용으로 장부 기록
```

예를 들어 월 실제 결제금액이 30,000원이라면 KRIM 장부에서는 개념적으로:

```text
2026-09-xx
항목: ChatGPT 이용료
분류: 소프트웨어/SaaS
금액: 30,000원
용도: 외주개발 / 코드 작성 / 문서작성 / 사업기획
결제: 사업용 카드
증빙: OpenAI Invoice + 카드전표
```

처럼 관리하면 된다.

중요한 점은 **청구정보를 지금 변경해도 과거에 이미 발행된 인보이스가 자동으로 사업자 정보로 바뀌지는 않는다**는 것이다. OpenAI도 변경된 청구 정보는 향후 인보이스부터 적용된다고 명시하고 있다. citeturn0search0

그리고 **경비 인정(종합소득세 필요경비)**과 **부가세 매입세액 공제**는 별개의 문제야. 특히 OpenAI 같은 해외 전자서비스 결제는 국내 업체에서 받은 일반 세금계산서와 똑같이 생각하면 안 된다.

그러니까 지금 네 상황에서는 **개인 ChatGPT 계정을 그대로 유지하면서 `계림 사업자 청구정보 등록 + 사업용 카드 결제 + Invoice 보관`으로 바꾸는 방향**을 추천해.

원하면 내가 다음으로 **현재 ChatGPT 설정에서 계림 사업자번호를 어디에 입력하고, 어떤 항목을 어떻게 작성하면 되는지** 화면 기준으로 하나씩 같이 해줄게.
